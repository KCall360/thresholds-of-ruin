# Rogue monster concept sheets

The maintainer's concept sheets for the Rogue scenario's monsters. They are
aspirational targets for the procedural 3D recipes described in the
[Rogue creature models plan](../../plans/rogue-creature-models.md), not
renders of the client. Keep the compact Bold Storybook proportions of the
[art direction](../3d-art-direction.md) rather than copying the sheets' taller
figures.
