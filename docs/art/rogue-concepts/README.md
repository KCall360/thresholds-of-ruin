# Rogue monster concept sheets

The maintainer's concept sheets for the Rogue scenario's monsters. The
[2026-10-20 Bold Storybook set](bold-storybook-2026-10-20/README.md) is the current
reference set for all 26 monsters,
and includes the approved humanoid body anchor. Its index and hash manifest
preserve all 25 supplied PNGs: 24 creature sheets and the named anchor.

Ice Monster's supplied direction is under reconsideration. Keep its sheet for
provenance, but defer its refinement until the maintainer chooses a direction.

Rattlesnake uses an extended default rest with its head and rattle raised.
This follows the maintainer's newer pose direction and supersedes its sheet's
coiled resting pose.

These are aspirational references for the procedural 3D recipes described in
the [Rogue creature models plan](../../plans/rogue-creature-models.md), not client
renders or visual acceptance evidence. The authoritative
[Bold Storybook definition](../3d-art-direction.md#proportions-bold-storybook)
governs anatomy, proportions, costume and animation; it takes precedence over
incidental annotations or conflicting details in an image. Reference art does
not add gameplay mechanics or change server disclosure rules.
